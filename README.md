# OpenWorkBuddy

> 腾讯 WorkBuddy 的开源替代方案

**数据主权归你，商业风险为零。**

---

## 为什么选择 OpenWorkBuddy？

你的企业数据，正在被偷偷上传别人的服务器上，比如claude code会收集你每一个鼠标、键盘操作行为这些数据，阿里巴巴内部安全团队已经证实，评估风险很高，在阿里内全面禁用，同样的其它的agent工具，比如zcode把全量的用户代码仓库上传到他们的服务。这些公司是狗改不了吃祥，就是他们再怎么保证，也会收集你的数据的。


**OpenWorkBuddy 改变这一切：**

- 🔒 **数据 100% 自有** —— 全部部署在你自己的服务器上，数据不出内网，敏感信息零外泄
- 📤 **一键迁移** —— 内置腾讯 WorkBuddy 工作内勤迁移工具，历史数据平滑导入，无缝切换
- ⚖️ **商业安全无忧** —— 面向企业用户开源，无隐藏条款、无数据收集、无平台锁定，用得放心
- 💰 **成本可控** —— 没有按人头计费的订阅费，花费明明白白

---

## 适合谁用？

- ✅ **重视数据安全的企业**：客户资料、经营数据不允许离开自己的服务器
- ✅ **担心商业风险的公司**：不想泄露商业机密，需要长期稳定可控
- ✅ **正在使用腾讯 WorkBuddy 的团队**：希望无缝迁移到开源方案，摆脱数据收集顾虑
- ✅ **需要定制化的大中型企业**：开源代码完全可控，可按业务需求深度定制
